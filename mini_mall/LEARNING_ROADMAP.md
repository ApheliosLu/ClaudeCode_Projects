# mini_mall 学习复盘与全栈工程师路线图

> 本文记录：mini_mall 项目的学习价值复盘、成为全栈开发工程师的能力差距清单、3 个月行动路线。2026-08-16 与 Claude 讨论整理。

## 一、mini_mall 项目学习价值复盘

### 已获得的能力（实际踩坑换来的）

| 能力维度 | 具体收获 |
| --- | --- |
| 全栈链路 | 数据库建模 → 服务端逻辑 → 页面渲染 → 鉴权 → 部署思考，完整走通 |
| 现代 Next.js | App Router、RSC、Server Actions、proxy（middleware 演进）、路由组陷阱（[slug] vs [id] 同段冲突、路由组不产生 URL 前缀） |
| 工程安全思维 | 金额防篡改（服务端重算）、原子扣库存（防超卖）、状态机白名单、CAS 防竞态（TOCTOU）、水平越权（归属校验）、open redirect |
| 排障能力 | 9 个阶段几十个真实问题：Node 24 原生模块崩溃（better-sqlite3 → libsql）、Windows 中文编码（GBK → U+FFFD）、路由冲突、构建产物过期、端口占用 |
| 工程化流程 | git 分支管理、双轮审查（code review + security review）、E2E 测试（Playwright 21 项）、lint/tsc 门禁、开发实录（DEVELOPMENT_LOG.md） |

### 最有价值的部分
**DEVELOPMENT_LOG.md**——记录了每个错误的诊断过程与解决方案，是"错误集"，比成功代码更值钱。面试时能讲清"为什么换掉 better-sqlite3"比"我会 Next.js"更有说服力。

### 已知局限（诚实评估）
- 未真实部署、未经历多用户并发（并发安全仅在代码层验证）
- 业务复杂度有限（无 SKU/优惠券/评价/退款）
- 技术面窄：仅在 Next.js 生态内，未接触传统后端、独立数据库调优、Docker 等

## 二、成为全栈工程师的能力差距清单

### 第一层：吃透当前链路（深度）
1. **JavaScript 语言本身**：原型、闭包、事件循环、异步模型——框架会过时，语言原理不会
2. **数据库原理**：索引、事务隔离级别、SQL 优化（目前只用 ORM）
3. **网络基础**：HTTP、DNS、HTTPS、缓存、同源策略
4. **Linux 基础**：命令行、进程、权限（正经部署都在 Linux 上）
5. **第二个后端视角**：深入 Node 或学 Java/Go

### 第二层：工程化体系（广度）
- Docker + Nginx（部署标配）
- CI/CD（GitHub Actions）
- 单元/集成测试（Vitest/Jest——目前只有 E2E）
- Redis 缓存、消息队列
- 监控告警（Sentry）

### 第三层：计算机基础（求职硬门槛）
- 操作系统 + 计算机网络（面试重灾区）
- 数据结构与算法（LeetCode 100+ 题）

### 第四层：软实力
- 业务理解（需求 → 技术方案）
- 沟通协作（评审、跨团队）
- 英文文档阅读（已具备，持续保持）

## 三、3 个月行动路线

| 阶段 | 内容 |
| --- | --- |
| 第 1 个月 | 本项目部署上线（简历可展示）+ 补单元测试 + 系统学 JS 语言核心 |
| 第 2 个月 | Docker + GitHub Actions：项目容器化 + CI 自动化；深入 SQL/索引 |
| 第 3 个月 | 第二个有深度的项目（或深入开源源码）+ LeetCode 刷题 + 技术博客沉淀 |

## 四、总结

mini_mall 完成了"前后端链路从零到一"。下一步不是"再做一个项目"，而是：
1. **补齐原理**：语言、数据库、网络、操作系统
2. **补齐工具链**：Docker、CI、单元测试

原理决定走多深，工具链决定走多快。
